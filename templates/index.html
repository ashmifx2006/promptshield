PromptShield

A security layer that checks what an AI agent proposes to do before any tool runs. Each proposed action is scored on intent deviation, source risk, action sensitivity and permission risk, then marked ALLOW, REVIEW or BLOCK.

04 / Method

Security mechanism

Prompt injection hides instructions in content the agent reads, such as emails, web pages, retrieved documents and tool output. PromptShield does not try to spot the injected text. It asks whether the action the agent now wants to take is justified.

  • Intent deviation: does the action match what the user asked for? (keyword heuristic)
  • Source risk: how much can the origin of the influencing content be trusted?
  • Action sensitivity: how much damage could this action do?
  • Permission risk: is the agent authorized to do it?
